My Study Planner

A simple web tool that helps university students keep every assignment, revision task and deadline in one place, so nothing important is forgotten.

Study life in three pictures

About the App

University study is not difficult because of one big task, it is difficult because many small tasks arrive at the same time. A quiz, a group report, a lab sheet and a reading task can all fall in the same week, and they are usually written in different places: the learning management system, an email, a chat group, a paper notebook.

My Study Planner puts those tasks into one list. For every task the user records the task title, the course code and course name, the due date, a short description and any extra notes. Tasks can be edited when a deadline moves, and deleted when they are finished. The page always shows the current date and time, so the user can see at a glance how many days are left before the next deadline.

All task data is stored inside the browser with localStorage. Nothing is sent to a server, which keeps the tool fast, offline friendly and private.

About Me

This is my website assignment. I enjoyed learning HTML, CSS and JavaScript while building this simple study planner.

I usually plan my study week on Sunday evening. I write down the deadlines of the coming week first, then divide the work into small blocks of about two hours, because long blocks never survive a real timetable. When a week becomes crowded, I put the three most urgent tasks at the top of the list and finish them before touching anything else.

Building My Study Planner is also a way for me to practise front-end skills: HTML for structure, CSS for layout and JavaScript for interaction. Writing the code in small steps and testing each function in the browser taught me more than reading about JavaScript, and the two bugs recorded on the blog page were part of that learning.
